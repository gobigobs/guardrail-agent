⏸️
Approval gate
Consequential actions pause via LangGraph interrupt() and resume only with Command(resume=…). The tool runs after you say yes — never before.

    
🛡️
Guardrails in code
Risk tiers in config.py, one choke point in guardrails.classify(). The model proposes; code decides. It cannot talk its way past.

    
📋
Audit everything
Append-only SQLite log: every run, LLM call, plan, tool call, approval and refusal — with run id, timestamp and actor.

    
🚫
Refusals, logged
Database writes are refused with a reason and the SAMPLE database stays untouched — read-only connection as defence in depth.
